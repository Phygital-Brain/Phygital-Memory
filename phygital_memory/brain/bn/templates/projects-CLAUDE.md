প্রতিটা প্রজেক্ট একটা ফোল্ডার, যা তথ্য আসার সঙ্গে সঙ্গে বড় হয়। ঢোকার একটাই দরজা: `README.md`।

## কোথায় কী যাবে

| কী | কোথায় যাবে |
|---|---|
| সারসংক্ষেপ, অবস্থা, ডেডলাইন, পরের ধাপ | `প্রজেক্ট/{name}/README.md` |
| {Name}-এর কাজের নোট | `প্রজেক্ট/{name}/নোট/{topic}.md` |
| গবেষণা | `প্রজেক্ট/{name}/গবেষণা/{topic}.md` |
| ব্রিফ, স্পেসিফিকেশন, কী কী লাগবে | `প্রজেক্ট/{name}/ব্রিফ/{name}.md` |
| খসড়া, স্ক্রিপ্ট, লেখা | `প্রজেক্ট/{name}/খসড়া/{name}.md` |
| আইডিয়া | `প্রজেক্ট/{name}/আইডিয়া/{name}.md` |
| ফিডব্যাক | `প্রজেক্ট/{name}/ফিডব্যাক/{name}.md` |
| ছবি আর মিডিয়া | `প্রজেক্ট/{name}/মিডিয়া/` |
| এই প্রজেক্টের পুরোনো জিনিস | `প্রজেক্ট/{name}/আর্কাইভ/` |

ফোল্ডারের নাম ছোট হাতের অক্ষরে, শব্দের মাঝে হাইফেন, সামনে কোনো নম্বর নয় (`গবেষণা/`, `01-Research/` নয়)। এগুলোর কোনোটা না মিললে কোনো প্রজেক্ট নিজের ফোল্ডার যোগ করতে পারে।

## README কেমন হবে

1. ইনফো ব্লক (নিচে দেখুন), `description` সহ।
2. `## এটা কী`: এক বা দুই লাইন, [[লক্ষ্য]]-এর লিংকসহ।
3. `## অবস্থা আর পরের ধাপ`: কাজ কোথায় দাঁড়িয়ে, পরের ধাপ কী।
4. `## এটা কীভাবে চলে`: শুধু যদি স্বয়ংক্রিয় কিছু এখানে লেখে (কোনো নির্ধারিত টাস্ক, কোনো স্ক্রিপ্ট)।
5. `## কোথায় কী আছে`: শুধু সাবফোল্ডার তৈরি হলে। প্রতিটার লিংকসহ একটা ছোট টেবিল।

## ইনফো ব্লক (frontmatter)

```yaml
---
type: notes
date: 2026-10-13
status: active
project: Website-Redesign
tags: [website-redesign, notes]
---
```

- `type`: `project` (README, যাতে `created`, `updated` আর `description`-ও থাকে), `notes`, `research`, `brief`, `draft`, `idea`, `feedback`, `plan`।
- `status`: `active`, `paused` বা `done`। README-র অবস্থাই প্রজেক্টের অবস্থা।
- `project`: প্রজেক্ট ফোল্ডারের নাম।
- `tags`: আগে প্রজেক্ট, তারপর ধরন।

## নিয়ম

- নতুন প্রজেক্ট মানে শুধু একটা `README.md`। সাবফোল্ডার বানাবেন শুধু তখন, যখন এমন কিছু আসে যার জন্য দরকার, আর README থেকে সেগুলোর লিংক দেবেন।
- README হলো সূচিপত্র। সাবফোল্ডারের লেখা আবার সেখানে লিখবেন না।
- প্রজেক্টের ভেতরে কোনো `CLAUDE.md` নয়। একটা প্রজেক্টের নিজস্ব নিয়ম যায় নিচের "প্রজেক্ট অনুযায়ী নিয়ম"-এ।
- সংশ্লিষ্ট প্রতিটা নোটের ইনফো ব্লকে `project:` রাখুন।
- শেষ হওয়া প্রজেক্ট `স্মৃতি/আর্কাইভ/{name}/`-এ যায় শুধু তখন, যখন {Name} বলেন।
- প্রতিটা প্রজেক্ট [[লক্ষ্য]]-এর কোনো একটা লক্ষ্যের কাজে লাগা উচিত। চেক-আপের সময় যেসব লক্ষ্যের কোনো প্রজেক্ট নেই, আর যেসব প্রজেক্টের কোনো লক্ষ্য নেই, সেগুলো চিহ্নিত করুন।
