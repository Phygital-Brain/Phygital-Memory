Нотатки й уподобання для навичок, якими користується агент, а також Доглядач мозку.

## Структура

```
Навички/{skill-name}/
  {skill-name}.md або SKILL.md   що робить навичка
  notes.md                       як {Name} хоче, щоб працювала ця навичка
  references/                    приклади й довші матеріали
```

## Встановлено

| Навичка | Папка | Що робить |
|---|---|---|
| Доглядач мозку | `доглядач-мозку/` | Щоденне прибирання саме по собі і перевірка, коли {Name} просить |
| Ранковий огляд | `ранковий-огляд/` | Короткий план на день, на прохання або кожного робочого дня |
| Імпорт | `імпорт/` | Переносить нотатки з інших застосунків за планом, який {Name} спершу схвалює |
| Підготовка до зустрічі | `підготовка-до-зустрічі/` | Коротка довідка перед дзвінком із нотаток мозку |
| Інструменти мислення | `мислення/` | Покритикувати ідею, знайти закономірності, знайти нотатки, які суперечать одна одній |
| Підключені застосунки | `підключені-застосунки/` | З яких застосунків мозок бере інформацію і які для них правила |
| No AI Slop | `no-ai-slop/` | Перевірка тексту: редагує текст, щоб він звучав по-людськи, або позначає шаблони ШІ (автор Peter Yang, ліцензія MIT, ніколи не редагується) |

## Правила

- Одна папка на навичку, назва в kebab-case (малими літерами через дефіс).
- Коли додається нова навичка, додай рядок у таблицю вище.
- Щоб додати навичку або підключити застосунок, спершу переглянь, що пропонує Phygital Brain: `suggested-skills/README.md` і `suggested-apps/README.md` через конектор Phygital Brain або онлайн на https://github.com/Phygital-Brain/phygital-brain/tree/main/skills. Якщо потрібне там є, виконуй інструкції з його сторінки. Коли {Name} питає «що я можу додати до свого мозку?», «what can I add to my brain?», покажи обидва списки: спершу те, що підходить до роботи {Name}. Не показуй застосунки, які вже підключені, і навички, які вже встановлені.
- `SKILL.md`, отриманий від когось іншого, ніколи не редагується. Щоб підлаштувати навичку, додай `нотатки.md` у її папку.
- `доглядач-мозку/щоденне-прибирання.md` читає завдання за розкладом. Змінюй його лише для того, щоб змінити щоденний запуск, і тримай простим: без посилань, без блоків-виносок.
