ความรู้ที่สะสมไปเรื่อยๆ: การตัดสินใจ ข้อมูลค้นคว้า ใบสมัคร และของที่เก็บถาวร

## อะไรไปอยู่ที่ไหน

| เนื้อหา | ไปที่ |
|---|---|
| การตัดสินใจพร้อมเหตุผล หรือสิ่งที่ไปศึกษามาจากข้างนอก (แอป เว็บไซต์ คอร์ส คู่แข่ง) | `การตัดสินใจ/YYYY-MM-DD-{title}.md` |
| ข้อมูลค้นคว้า (ตลาด เทรนด์ ทางเลือกต่างๆ) | `ข้อมูลค้นคว้า/{topic}.md` |
| ใบสมัคร: งาน ทุน รางวัล งานเปิดรับผลงาน (สร้างเมื่อต้องใช้ครั้งแรก) | `ใบสมัคร/{name}/` |
| ข้อมูลคู่แข่ง (สร้างเมื่อต้องใช้ครั้งแรก) | `คู่แข่ง/{name}.md` |
| เรื่องเงิน: ใบแจ้งหนี้ ภาษี การจ่ายเงิน เป็นเรื่องส่วนตัว | `การเงิน/` |
| การตัดสินใจที่เก็บถาวรแล้ว | `เก็บถาวร/การตัดสินใจ/` |
| ข้อมูลค้นคว้าที่จบแล้วหรือเก่าแล้ว | `เก็บถาวร/ข้อมูลค้นคว้า/` |
| โปรเจกต์ที่จบแล้ว | `เก็บถาวร/{name}/` |
| บันทึกการประชุม | `การตัดสินใจ/` ถ้าได้ข้อสรุปเป็นการตัดสินใจ ถ้าไม่ใช่ ใส่ในบันทึก `บันทึกรายวัน/` ของวันนั้น เสนอให้มีโฟลเดอร์ประชุมแยกก็ต่อเมื่อมีเยอะมาก |

## บล็อกข้อมูล (frontmatter)

```yaml
---
type: research
date: 2026-10-13
status: active
tags: [research, pricing]
---
```

- `type`: `decision`, `research`, `application`, `competitor`
- `date`: วันที่เขียนโน้ต
- `status`: สำหรับการตัดสินใจและใบสมัคร ดูด้านล่าง อย่างอื่นทั้งหมด: `active` หรือ `closed`
- `tags`: ประเภทก่อน แล้วตามด้วยหัวข้อ
- ใส่หรือไม่ใส่ก็ได้: `project`, `deadline`, `description` (หนึ่งประโยคในเครื่องหมายคำพูด อยู่บรรทัดสุดท้าย)

## โน้ตการตัดสินใจ

ใส่เหตุผลไว้เสมอ: ใครเกี่ยวข้องบ้าง อะไรทำให้ต้องตัดสินใจ และยอมแลกอะไรไป ใช้ `> [!important]` กับตัวการตัดสินใจ และ `> [!warning]` กับความเสี่ยงที่รู้อยู่แล้ว

การตัดสินใจมี `updated:` ต่อจาก `date:` ด้วย `date` คือวันที่สร้าง `updated` คือครั้งล่าสุดที่ทบทวนหรือเปลี่ยน

```yaml
---
type: decision
date: 2026-09-02
updated: 2026-10-13
status: open
tags: [decision, website]
---
```

- `status`: `open` (ยังตัดสินใจหรือยังทำอยู่), `waiting` (รอคนอื่น), `paused`, `closed`
- การตัดสินใจที่ `updated` เก่ากว่า 30 วันต้องทบทวน ผู้ช่วยจัดระเบียบจะแจ้งเตือนไปเรื่อยๆ จนกว่า {Name} จะเก็บไว้ ปิด หรือเก็บถาวร (ทั้งสามแบบจะตั้ง `updated` เป็นวันนั้น)
- การตัดสินใจย้ายไป `เก็บถาวร/การตัดสินใจ/` ก็ต่อเมื่อ {Name} บอกเท่านั้น

## ใบสมัคร

ใบสมัครละหนึ่งโฟลเดอร์: `ใบสมัคร/{name}/` มี `README.md` เก็บเดดไลน์ ลิงก์ สถานะ และสิ่งที่ส่งไป ไฟล์อื่นๆ (คำตอบ จดหมายแนะนำตัว) วางไว้ข้างกัน

- `status`: `draft`, `submitted`, `accepted`, `rejected` หรือ `withdrawn`
- เก็บคำตอบเป็น markdown ไฟล์ PDF และสไลด์ขนาดใหญ่เก็บไว้นอกสมอง แล้วสรุปไว้ในโน้ตแทน

## กฎ

- ข้อมูลค้นคว้าเป็นกลางโดยค่าเริ่มต้น (กฎหลักข้อ 23)
- ข้อมูลค้นคว้าที่มีของใหม่มาแทนแล้ว ให้ย้ายไป `เก็บถาวร/ข้อมูลค้นคว้า/` แทนการลบ
- `การเงิน/` เป็นเรื่องส่วนตัว และอยู่ในรายการของ `.claudeignore` เปิดได้ก็ต่อเมื่อ {Name} ขอไฟล์ที่เจาะจง (กฎหลักข้อ 8)
