हर प्रोजेक्ट एक फ़ोल्डर है, जो जानकारी आने के साथ बढ़ता जाता है। `README.md` उसका मुख्य पेज है, सब कुछ वहीं से शुरू होता है।

## कहाँ क्या जाए

| क्या है | कहाँ जाए |
|---|---|
| झलक, स्टेटस, डेडलाइन, अगले कदम | `प्रोजेक्ट/{name}/README.md` |
| {Name} के काम के नोट्स | `प्रोजेक्ट/{name}/नोट्स/{topic}.md` |
| रिसर्च | `प्रोजेक्ट/{name}/रिसर्च/{topic}.md` |
| ब्रीफ़, स्पेसिफ़िकेशन, ज़रूरतें | `प्रोजेक्ट/{name}/ब्रीफ़/{name}.md` |
| ड्राफ़्ट, स्क्रिप्ट, लिखा हुआ कंटेंट | `प्रोजेक्ट/{name}/ड्राफ़्ट/{name}.md` |
| आइडिया | `प्रोजेक्ट/{name}/आइडिया/{name}.md` |
| फ़ीडबैक | `प्रोजेक्ट/{name}/फ़ीडबैक/{name}.md` |
| तस्वीरें और मीडिया | `प्रोजेक्ट/{name}/मीडिया/` |
| इस प्रोजेक्ट का पुराना सामान | `प्रोजेक्ट/{name}/आर्काइव/` |

फ़ोल्डरों के नाम में हाइफ़न होते हैं और आगे कोई नंबर नहीं (`रिसर्च/`, `01-Research/` नहीं)। जब इनमें से कोई फ़िट न हो, तो प्रोजेक्ट अपना फ़ोल्डर जोड़ सकता है।

## README का ढाँचा

1. इन्फ़ो ब्लॉक (नीचे), `description` के साथ।
2. `## यह क्या है`: एक या दो लाइनें, [[लक्ष्य]] से जुड़ी हुई।
3. `## स्टेटस और अगला कदम`: अभी कहाँ तक पहुँचा, अगला कदम।
4. `## यह कैसे चलता है`: सिर्फ़ तब, जब यहाँ कोई चीज़ अपने आप लिखती हो (कोई शेड्यूल किया हुआ टास्क, कोई स्क्रिप्ट)।
5. `## कौन-सी चीज़ कहाँ है`: सिर्फ़ तब, जब सबफ़ोल्डर बन चुके हों। हर एक के लिंक वाली एक छोटी टेबल।

## इन्फ़ो ब्लॉक (frontmatter)

```yaml
---
type: notes
date: 2026-10-13
status: active
project: Website-Redesign
tags: [website-redesign, notes]
---
```

- `type`: `project` (README, जिसमें `created`, `updated` और `description` भी होते हैं), `notes`, `research`, `brief`, `draft`, `idea`, `feedback`, `plan`।
- `status`: `active`, `paused` या `done`। README का स्टेटस ही प्रोजेक्ट का स्टेटस है।
- `project`: प्रोजेक्ट फ़ोल्डर का नाम।
- `tags`: पहले प्रोजेक्ट, फिर टाइप।

## नियम

- नया प्रोजेक्ट बस एक `README.md` होता है। सबफ़ोल्डर तभी बनाएँ जब ऐसा कंटेंट आए जिसे उनकी ज़रूरत हो, और README से उनका लिंक दें।
- README ही इंडेक्स है। सबफ़ोल्डर की बातें उसमें दोबारा न लिखें।
- प्रोजेक्ट के अंदर कोई `CLAUDE.md` नहीं। किसी एक प्रोजेक्ट के नियम नीचे "हर प्रोजेक्ट के अपने नियम" में जाते हैं।
- हर जुड़े हुए नोट के इन्फ़ो ब्लॉक में `project:` लिखें।
- पूरा हो चुका प्रोजेक्ट `याददाश्त/आर्काइव/{name}/` में तभी जाता है जब {Name} कहें।
- हर प्रोजेक्ट को [[लक्ष्य]] के किसी लक्ष्य के काम आना चाहिए। चेक-अप में, बिना प्रोजेक्ट वाले लक्ष्य और बिना लक्ष्य वाले प्रोजेक्ट बताएँ।
