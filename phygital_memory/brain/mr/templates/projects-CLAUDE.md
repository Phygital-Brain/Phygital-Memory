प्रत्येक प्रकल्प एक फोल्डर असतो, जो माहिती येईल तसा वाढत जातो. `README.md` हे आत जाण्याचे एकमेव दार आहे.

## कुठे काय जाते

| मजकूर | कुठे जातो |
|---|---|
| थोडक्यात माहिती, सद्यस्थिती, अंतिम तारीख, पुढच्या पायऱ्या | `प्रकल्प/{name}/README.md` |
| {Name} यांच्या कामाच्या नोट्स | `प्रकल्प/{name}/नोट्स/{topic}.md` |
| संशोधन | `प्रकल्प/{name}/संशोधन/{topic}.md` |
| ब्रीफ, तपशीलवार वर्णन, गरजा | `प्रकल्प/{name}/ब्रीफ/{name}.md` |
| मसुदे, स्क्रिप्ट, लिहिलेला मजकूर | `प्रकल्प/{name}/मसुदे/{name}.md` |
| कल्पना | `प्रकल्प/{name}/कल्पना/{name}.md` |
| अभिप्राय | `प्रकल्प/{name}/अभिप्राय/{name}.md` |
| चित्रे आणि मीडिया | `प्रकल्प/{name}/मीडिया/` |
| या प्रकल्पाचे जुने साहित्य | `प्रकल्प/{name}/जुने/` |

फोल्डरची नावे लहान अक्षरांत, शब्दांमध्ये हायफन, सुरुवातीला क्रमांक नाही (`संशोधन/`, `01-Research/` नाही). यांपैकी काहीच बसत नसेल तर प्रकल्प स्वतःचा फोल्डर जोडू शकतो.

## README ची मांडणी

1. माहिती-ब्लॉक (खाली पाहा), `description` सह.
2. `## हे काय आहे`: एक-दोन ओळी, [[ध्येये]] या नोटला लिंक केलेल्या.
3. `## सद्यस्थिती आणि पुढची पायरी`: काम कुठपर्यंत आले, पुढची पायरी.
4. `## हे कसे चालते`: फक्त एखादी आपोआप चालणारी गोष्ट इथे लिहीत असेल तर (ठरलेल्या वेळी चालणारे काम, एखादी स्क्रिप्ट).
5. `## काय कुठे आहे`: उपफोल्डर बनल्यावरच. प्रत्येकाला लिंक करणारा एक छोटा तक्ता.

## माहिती-ब्लॉक (frontmatter)

```yaml
---
type: notes
date: 2026-10-13
status: active
project: Website-Redesign
tags: [website-redesign, notes]
---
```

- `type`: `project` (README, ज्यात `created`, `updated` आणि `description` पण असतात), `notes`, `research`, `brief`, `draft`, `idea`, `feedback`, `plan`.
- `status`: `active`, `paused` किंवा `done`. README ची स्थिती हीच प्रकल्पाची स्थिती.
- `project`: प्रकल्पाच्या फोल्डरचे नाव.
- `tags`: आधी प्रकल्प, मग प्रकार.

## नियम

- नवीन प्रकल्प म्हणजे फक्त एक `README.md`. ज्यांची गरज आहे असा मजकूर आल्यावरच उपफोल्डर बनवा, आणि README मधून त्यांना लिंक करा.
- README ही अनुक्रमणिका आहे. उपफोल्डरमधील मजकूर त्यात पुन्हा लिहू नका.
- प्रकल्पाच्या आत `CLAUDE.md` नाही. एकाच प्रकल्पाचे नियम खाली "प्रत्येक प्रकल्पाचे नियम" मध्ये जातात.
- संबंधित प्रत्येक नोटच्या माहिती-ब्लॉकमध्ये `project:` लिहा.
- पूर्ण झालेला प्रकल्प `स्मृती/जुने/{name}/` मध्ये तेव्हाच जातो जेव्हा {Name} तसे सांगतात.
- प्रत्येक प्रकल्प [[ध्येये]] मधील एखाद्या ध्येयासाठी असावा. तपासणीमध्ये, प्रकल्प नसलेली ध्येये आणि ध्येय नसलेले प्रकल्प दाखवून द्या.
