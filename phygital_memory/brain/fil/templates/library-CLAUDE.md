Ang aklatan ng content na magagamit ulit: prompt, template, framework, mga sanggunian. Panatilihin itong maliit.

## Mga patakaran

- Kapag may ibinahagi si {Name} na magagamit ulit, i-save ito dito na may malinaw na pangalan ng file.
- Gumawa lang ng subfolder kapag may ilang file na ng iisang uri (halimbawa `prompt/`, `template/`, `framework/`).
- I-link ang mga resource mula sa mga project at note ng araw gamit ang `[[wikilink]]`.
- Ang research ay nasa `Alaala/`, ang mga file ng aktibong project ay nasa `Proyekto/`. Huwag doblehin dito. Mag-link sa kanila.
- Walang kopya ng mga file na nada-download o ng gawa ng ibang tao. Isulat na lang kung saan makukuha ang mga ito.
