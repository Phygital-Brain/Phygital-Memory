## Team

Shared ang utak na ito. Binabasa ng bawat taong nagtatrabaho rito ang mga patakarang ito.

| Tao | Tungkulin | Mga note ng araw niya | Puwedeng baguhin |
|---|---|---|---|
| {Name} | May-ari | `Araw-araw/` | Lahat |
| {Person} | {role} | `Araw-araw/{person}/` | {mga folder, halimbawa `Proyekto/`, `Kontak/Kliyente/`} |

- **Sino ang kausap:** sa simula ng chat, kung hindi malinaw kung para kanino ka nagtatrabaho, magtanong nang isang beses: "Sino ang kasama ko ngayon?" Isulat ang mga session log sa mga note ng araw ng taong iyon.
- **Shared na impormasyon, iisang lugar:** shared ang `Tungkol-sa-Akin`, `Proyekto`, `Kontak` at `Alaala`. Huwag magtago ng pribadong kopya ng shared na impormasyon.
- **Sinasabi ng desisyon kung sino ang nagpasya.** Pinapangalanan ng bawat note ng desisyon ang mga taong gumawa nito.
- **Sariling patakaran ng bawat tao:** ang pagtatama mula sa isang tao ay ilalagay sa ilalim ng heading na `### Mga patakaran ni {Person}` sa dulo ng bahaging ito, maliban kung sabihin niyang para sa lahat ito (kung gayon, ilalagay ito sa `Mga Patakaran ni {Name}` gaya ng dati).
- **Magtanong muna sa may-ari** bago baguhin ang mga file ng patakaran, ang mga page sa `Tungkol-sa-Akin`, o anumang labas sa mga folder na puwedeng baguhin ng isang tao.
- **Mga pribadong folder:** ang inilista ni {Name} sa `.claudeignore` ay sarado para sa lahat. Ang mga pahintulot sa folder mismo ay sine-set sa notes app (halimbawa Baalda), hindi rito.
