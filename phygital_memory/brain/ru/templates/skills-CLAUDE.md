Заметки и предпочтения для навыков, которыми пользуется агент, плюс Хранитель мозга.

## Структура

```
Навыки/{skill-name}/
  {skill-name}.md или SKILL.md   что делает навык
  notes.md                       голос и предпочтения владельца для этого навыка
  references/                    примеры и материалы подлиннее
```

## Установлено

| Навык | Папка | Что делает |
|---|---|---|
| Хранитель мозга | `хранитель-мозга/` | Сам наводит порядок каждый день и проводит проверку, когда {Name} просит |
| Утренняя сводка | `утренняя-сводка/` | Короткий план на день, по запросу или каждый рабочий день |
| Импорт | `импорт/` | Переносит заметки из других приложений по плану, который {Name} сначала одобряет |
| Подготовка к встрече | `подготовка-к-встрече/` | Короткая сводка перед созвоном по заметкам мозга |
| Инструменты мышления | `мышление/` | Критикуют идею, находят закономерности и заметки, которые противоречат друг другу |
| Подключенные приложения | `подключенные-приложения/` | Из каких приложений мозг берет информацию и какие для них правила |
| No AI Slop | `no-ai-slop/` | «Проверка текста»: правит тексты, чтобы они звучали по-человечески, или отмечает шаблоны ИИ (автор Peter Yang, лицензия MIT, никогда не редактируется) |

## Правила

- Одна папка на навык, название в стиле kebab-case (строчные буквы через дефис).
- Когда добавляется новый навык, добавь строку в таблицу выше.
- Чтобы добавить навык или подключить приложение, сначала посмотри, что предлагает Phygital Brain: `suggested-skills/README.md` и `suggested-apps/README.md` через коннектор Phygital Brain или онлайн по адресу https://github.com/Phygital-Brain/phygital-brain/tree/main/skills. Если нужное там есть, следуй его странице. Когда {Name} спрашивает «что можно добавить в мой мозг?», «what can I add to my brain?», покажи оба списка: сначала то, что подходит к тому, чем занимается {Name}, и не показывай приложения, которые уже подключены, и навыки, которые уже установлены.
- `SKILL.md`, который пришел от кого-то другого, никогда не редактируется. Чтобы настроить навык под себя, добавь `заметки.md` в его папку.
- `хранитель-мозга/ежедневная-уборка.md` читает задача по расписанию. Меняй его, только чтобы изменить ежедневный запуск, и держи его простым: без ссылок и без выносок.
