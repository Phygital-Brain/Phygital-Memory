Библиотека материалов, которые пригодятся не раз: промпты, шаблоны, методики, справочные материалы. Держи ее небольшой.

## Правила

- Когда {Name} делится чем-то полезным на будущее, сохрани это здесь под понятным названием файла.
- Подпапки создавай, только когда набирается несколько файлов одного вида (например, `промпты/`, `шаблоны/`, `методики/`).
- Ставь ссылки на материалы из проектов и заметок дня с помощью `[[вики-ссылок]]`.
- Исследования лежат в `Память/`, рабочие файлы проектов в `Проекты/`. Не дублируй их здесь, ставь ссылку.
- Не храни копии файлов, которые можно скачать, и чужие работы. Вместо этого запиши, где их взять.
