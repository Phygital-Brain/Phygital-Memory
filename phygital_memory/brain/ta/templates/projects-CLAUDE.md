ஒவ்வொரு திட்டமும் ஒரு ஃபோல்டர், தகவல் வர வர அது வளரும். `README.md` தான் ஒரே நுழைவு வாயில்.

## எது எங்கே போகும்

| உள்ளடக்கம் | எங்கே |
|---|---|
| மேலோட்டம், நிலை, கடைசித் தேதி, அடுத்த படிகள் | `திட்டங்கள்/{name}/README.md` |
| {Name}-இன் வேலைக் குறிப்புகள் | `திட்டங்கள்/{name}/குறிப்புகள்/{topic}.md` |
| ஆய்வு | `திட்டங்கள்/{name}/ஆய்வு/{topic}.md` |
| பிரீஃப், விவரக்குறிப்பு, தேவைகள் | `திட்டங்கள்/{name}/பிரீஃப்கள்/{name}.md` |
| வரைவுகள், ஸ்கிரிப்ட்கள், எழுதிய உள்ளடக்கம் | `திட்டங்கள்/{name}/வரைவுகள்/{name}.md` |
| யோசனைகள் | `திட்டங்கள்/{name}/யோசனைகள்/{name}.md` |
| கருத்துகள் | `திட்டங்கள்/{name}/கருத்துகள்/{name}.md` |
| படங்களும் மீடியாவும் | `திட்டங்கள்/{name}/மீடியா/` |
| இந்தத் திட்டத்தின் பழைய பொருட்கள் | `திட்டங்கள்/{name}/காப்பகம்/` |

ஃபோல்டர் பெயர்கள் சிறிய எழுத்துகளில், சொற்களுக்கு இடையே hyphen, முன்னால் எண்கள் இல்லாமல் (`ஆய்வு/`, `01-Research/` அல்ல). இவற்றில் எதுவும் பொருந்தாதபோது, ஒரு திட்டம் தனக்கென ஒரு ஃபோல்டரைச் சேர்க்கலாம்.

## README அமைப்பு

1. தகவல் பகுதி (கீழே), ஒரு `description`-உடன்.
2. `## இது என்ன`: ஒன்று அல்லது இரண்டு வரிகள், [[இலக்குகள்]]-க்கு லிங்க் உடன்.
3. `## நிலையும் அடுத்த படியும்`: இப்போது எங்கே நிற்கிறது, அடுத்த படி.
4. `## இது எப்படி இயங்குகிறது`: தானாக இயங்கும் ஏதாவது (ஒரு திட்டமிட்ட டாஸ்க், ஒரு ஸ்கிரிப்ட்) இங்கே எழுதினால் மட்டும்.
5. `## எது எங்கே இருக்கிறது`: துணை ஃபோல்டர்கள் வந்த பிறகு மட்டும். ஒவ்வொன்றுக்கும் லிங்க் கொடுக்கும் ஒரு சின்ன அட்டவணை.

## தகவல் பகுதி (frontmatter)

```yaml
---
type: notes
date: 2026-10-13
status: active
project: Website-Redesign
tags: [website-redesign, notes]
---
```

- `type`: `project` (README, அதில் `created`, `updated`, `description`-உம் இருக்கும்), `notes`, `research`, `brief`, `draft`, `idea`, `feedback`, `plan`.
- `status`: `active`, `paused` அல்லது `done`. README-இன் நிலைதான் திட்டத்தின் நிலை.
- `project`: திட்ட ஃபோல்டரின் பெயர்.
- `tags`: திட்டம், பிறகு வகை.

## விதிகள்

- ஒரு புதிய திட்டம் என்பது ஒரு `README.md` மட்டுமே. தேவைப்படும் உள்ளடக்கம் வரும்போது மட்டுமே துணை ஃபோல்டர்களை உருவாக்கி, README-இலிருந்து லிங்க் கொடுங்கள்.
- README தான் அட்டவணை. துணை ஃபோல்டர்களின் உள்ளடக்கத்தை அதில் திரும்ப எழுதாதீர்கள்.
- ஒரு திட்டத்துக்குள் `CLAUDE.md` வேண்டாம். ஒரு திட்டத்துக்கான விதிகள் கீழே "ஒவ்வொரு திட்டத்துக்குமான விதிகள்" பகுதியில் போகும்.
- தொடர்புடைய ஒவ்வொரு குறிப்பின் தகவல் பகுதியிலும் `project:` சேருங்கள்.
- {Name} சொன்னால் மட்டுமே முடிந்த திட்டம் `நினைவகம்/காப்பகம்/{name}/`-க்குப் போகும்.
- ஒவ்வொரு திட்டமும் [[இலக்குகள்]]-இல் உள்ள ஒரு இலக்குக்கு உதவ வேண்டும். செக்-அப்பில், திட்டம் இல்லாத இலக்குகளையும் இலக்கு இல்லாத திட்டங்களையும் சுட்டிக்காட்டுங்கள்.
