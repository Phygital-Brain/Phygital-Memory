# phygital-memory

Installs [Phygital Memory](https://github.com/Phygital-Brain/Phygital-Memory), a notes app that becomes your second brain. Open source, private, encrypted when you want it, and every file stays yours.

```bash
npx phygital-memory
```

It downloads the latest version for your computer from GitHub Releases and installs it: Mac, Windows, or Linux (Ubuntu and Debian, Fedora and openSUSE, or an AppImage for the rest). It needs Node.js 18 or newer.

After that the app keeps itself up to date.
