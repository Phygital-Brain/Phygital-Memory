The library of reusable content: prompts, templates, frameworks, reference material. Keep it small.

## Rules

- When {Name} shares something reusable, save it here with a clear file name.
- Create subfolders only when there are several files of one kind (for example `prompts/`, `templates/`, `frameworks/`).
- Link resources from projects and daily notes with `[[wikilinks]]`.
- Research goes in `Memory/`, live project files in `Projects/`. Don't duplicate them here. Link to them.
- No copies of downloadable files or other people's work. Note where to get them instead.
