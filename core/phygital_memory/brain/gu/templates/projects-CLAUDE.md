દરેક પ્રોજેક્ટ એક ફોલ્ડર છે, જે માહિતી આવતી જાય તેમ મોટું થાય છે. `README.md` પ્રોજેક્ટનું મુખ્ય પાનું છે: બધું ત્યાંથી જ શરૂ થાય છે.

## શું ક્યાં જાય

| શું છે | ક્યાં જાય |
|---|---|
| ઝાંખી, સ્થિતિ, ડેડલાઇન, આગળનાં પગલાં | `પ્રોજેક્ટ/{name}/README.md` |
| {Name}ની કામની નોંધો | `પ્રોજેક્ટ/{name}/નોંધો/{topic}.md` |
| રિસર્ચ | `પ્રોજેક્ટ/{name}/રિસર્ચ/{topic}.md` |
| બ્રીફ, સ્પેક, જરૂરિયાતો | `પ્રોજેક્ટ/{name}/બ્રીફ/{name}.md` |
| ડ્રાફ્ટ, સ્ક્રિપ્ટ, લખાણ | `પ્રોજેક્ટ/{name}/ડ્રાફ્ટ/{name}.md` |
| આઇડિયા | `પ્રોજેક્ટ/{name}/આઇડિયા/{name}.md` |
| પ્રતિભાવ | `પ્રોજેક્ટ/{name}/પ્રતિભાવ/{name}.md` |
| ચિત્રો અને મીડિયા | `પ્રોજેક્ટ/{name}/મીડિયા/` |
| આ પ્રોજેક્ટની જૂની સામગ્રી | `પ્રોજેક્ટ/{name}/આર્કાઇવ/` |

ફોલ્ડરનાં નામ નાના અક્ષરે, હાઇફન સાથે, આગળ નંબર વગર (`રિસર્ચ/`, `01-Research/` નહીં). જો આમાંનું કોઈ બંધબેસતું ન હોય, તો પ્રોજેક્ટ પોતાનું ફોલ્ડર ઉમેરી શકે.

## READMEની ગોઠવણ

1. માહિતી બ્લોક (નીચે જુઓ), `description` સાથે.
2. `## આ શું છે`: એક કે બે લાઇન, [[ધ્યેય]]ની લિંક સાથે.
3. `## સ્થિતિ અને આગળનું પગલું`: કામ ક્યાં પહોંચ્યું, આગળનું પગલું.
4. `## આ કેવી રીતે ચાલે છે`: ફક્ત ત્યારે, જ્યારે કંઈ આપમેળે અહીં લખતું હોય (શેડ્યૂલ કરેલું કામ, કોઈ સ્ક્રિપ્ટ).
5. `## કઈ વસ્તુ ક્યાં છે`: ફક્ત સબફોલ્ડર બને પછી. દરેકની લિંક આપતું એક નાનું ટેબલ.

## માહિતી બ્લોક (frontmatter)

```yaml
---
type: notes
date: 2026-10-13
status: active
project: Website-Redesign
tags: [website-redesign, notes]
---
```

- `type`: `project` (README, જેમાં `created`, `updated` અને `description` પણ હોય), `notes`, `research`, `brief`, `draft`, `idea`, `feedback`, `plan`.
- `status`: `active`, `paused` કે `done`. READMEની સ્થિતિ એ જ પ્રોજેક્ટની સ્થિતિ.
- `project`: પ્રોજેક્ટ ફોલ્ડરનું નામ.
- `tags`: પહેલાં પ્રોજેક્ટ, પછી પ્રકાર.

## નિયમો

- નવો પ્રોજેક્ટ એટલે ફક્ત એક `README.md`. સબફોલ્ડર ત્યારે જ બનાવો જ્યારે એવી સામગ્રી આવે જેને તેની જરૂર હોય, અને READMEમાંથી તેની લિંક આપો.
- README એ અનુક્રમણિકા છે. સબફોલ્ડરની સામગ્રી તેમાં ફરીથી ન લખો.
- પ્રોજેક્ટની અંદર કોઈ `CLAUDE.md` નહીં. ફક્ત એક પ્રોજેક્ટ માટેના નિયમો નીચે "દરેક પ્રોજેક્ટના પોતાના નિયમો"માં જાય.
- પ્રોજેક્ટને લગતી દરેક નોંધના માહિતી બ્લોકમાં `project:` લખો.
- પૂરો થયેલો પ્રોજેક્ટ `સ્મૃતિ/આર્કાઇવ/{name}/`માં ત્યારે જ જાય જ્યારે {Name} કહે.
- દરેક પ્રોજેક્ટ [[ધ્યેય]]ના કોઈ ધ્યેય માટે હોવો જોઈએ. ચેક-અપમાં, પ્રોજેક્ટ વગરના ધ્યેય અને ધ્યેય વગરના પ્રોજેક્ટ બતાવો.
