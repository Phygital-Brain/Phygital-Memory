ஏஜென்ட் பயன்படுத்தும் திறன்களுக்கான குறிப்புகளும் விருப்பங்களும், கூடவே பிரெயின் கீப்பர்.

## அமைப்பு

```
திறன்கள்/{skill-name}/
  {skill-name}.md or SKILL.md   திறன் என்ன செய்கிறது
  notes.md                      இந்தத் திறனுக்கான {Name}-இன் குரலும் விருப்பங்களும்
  references/                   உதாரணங்களும் நீண்ட பொருட்களும்
```

## நிறுவப்பட்டவை

| திறன் | ஃபோல்டர் | என்ன செய்கிறது |
|---|---|---|
| பிரெயின் கீப்பர் | `பிரெயின்-கீப்பர்/` | தினமும் தானாக ஒழுங்குபடுத்துதல், {Name} கேட்கும்போது ஒரு செக்-அப் |
| காலைச் சுருக்கம் | `காலைச்-சுருக்கம்/` | அன்றைய நாளுக்கான ஒரு சின்னத் திட்டம், கேட்கும்போது அல்லது ஒவ்வொரு வேலை நாளும் |
| இறக்குமதி | `இறக்குமதி/` | மற்ற ஆப்களிலிருந்து குறிப்புகளைக் கொண்டு வருகிறது, {Name} முதலில் ஒப்புக்கொள்ளும் ஒரு திட்டத்துடன் |
| மீட்டிங் தயாரிப்பு | `மீட்டிங்-தயாரிப்பு/` | ஒரு காலுக்கு முன், பிரெயினின் குறிப்புகளிலிருந்து ஒரு சின்னச் சுருக்கம் |
| சிந்தனைக் கருவிகள் | `சிந்தனை/` | ஒரு யோசனையைச் சோதிக்கிறது, பேட்டர்ன்களைக் கண்டுபிடிக்கிறது, ஒன்றுக்கொன்று முரண்படும் குறிப்புகளைக் கண்டுபிடிக்கிறது |
| இணைத்த ஆப்கள் | `இணைத்த-ஆப்கள்/` | பிரெயின் எந்த ஆப்களிலிருந்து படிக்கிறது, அவற்றுக்கான விதிகள் |
| No AI Slop | `no-ai-slop/` | எழுத்துச் சரிபார்ப்பு: எழுத்தை மனிதர் எழுதியது போல மாற்றுகிறது, அல்லது AI பேட்டர்ன்களைச் சுட்டிக்காட்டுகிறது (Peter Yang உருவாக்கியது, MIT License, ஒருபோதும் மாற்றப்படாது) |

## விதிகள்

- ஒரு திறனுக்கு ஒரு ஃபோல்டர், kebab-case பெயருடன்.
- புதிய திறன் சேர்க்கப்படும்போது, மேலே உள்ள அட்டவணையில் ஒரு வரியைச் சேருங்கள்.
- ஒரு திறனைச் சேர்க்க அல்லது ஒரு ஆப்பை இணைக்க, முதலில் Phygital Brain பரிந்துரைப்பவற்றைப் பாருங்கள்: Phygital Brain கனெக்டர் வழியாக `suggested-skills/README.md`, `suggested-apps/README.md`, அல்லது ஆன்லைனில் https://github.com/Phygital-Brain/phygital-brain/tree/main/skills. அது அங்கே இருந்தால், அதன் பக்கத்தில் சொன்னபடி செய்யுங்கள். {Name} "என் பிரெயினில் என்ன சேர்க்கலாம்?", "what can I add to my brain?" என்று கேட்கும்போது, இரண்டு பட்டியல்களையும் காட்டுங்கள்: {Name}-இன் வேலைக்குப் பொருந்துபவை முதலில். ஏற்கனவே இணைத்த ஆப்களையும் ஏற்கனவே நிறுவிய திறன்களையும் விட்டுவிடுங்கள்.
- வேறொருவரிடமிருந்து வந்த `SKILL.md` ஒருபோதும் மாற்றப்படாது. ஒரு திறனை உங்களுக்கு ஏற்றபடி மாற்ற, அதன் ஃபோல்டரில் `குறிப்புகள்.md` சேருங்கள்.
- `பிரெயின்-கீப்பர்/தினசரி-சுத்தம்.md`-ஐ ஒரு திட்டமிட்ட டாஸ்க் படிக்கிறது. தினசரி ஓட்டம் என்ன செய்கிறது என்பதை மாற்ற மட்டுமே அதை மாற்றுங்கள், அதை எளிமையாக வையுங்கள்: லிங்க்குகள் இல்லை, கால்அவுட்கள் இல்லை.
