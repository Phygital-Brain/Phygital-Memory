Ipinapasok ang mga note mula sa ibang apps papunta sa utak na ito, kahit kailan pagkatapos ng setup. Paano mag-export mula sa bawat app: https://github.com/Phygital-Brain/phygital-brain/blob/main/docs/importing.md

Trigger: "ipasok ang mga luma kong note", "bring in my old notes", "i-import ang mga note na ito", "import these notes", o ang katumbas sa {Language}. Pati na rin kapag nag-drop si {Name} ng export (isang Notion folder, Google Docs, text mula sa Apple Notes, mga file ng Evernote, mga Markdown file).

## 1. Basahin, walang babaguhin

Basahin ang lahat ng ibinigay ni {Name}. Kung malaki ang export, itanong kung aling bahagi ang uunahin ("ang mga note mo muna tungkol sa kliyente?") at gawin ito nang tig-30 note bawat batch.

Laktawan ang hindi dapat isama: password, key, token at mga pribadong numero (pangunahing patakaran 25 at 26). Huwag kailanman kopyahin ang mga ito sa utak. Sabihin kay {Name} kung aling mga file ang nilaktawan mo at bakit.

## 2. Gumawa ng plano

Para sa bawat piraso, pagpasyahan kung saan ito ilalagay gamit ang table na "Saan Ilalagay ang Bawat Bagay" sa pangunahing `CLAUDE.md`: isang project, isang tao o kumpanya, isang desisyon, research, isang item sa aklatan, isang detalye sa Tungkol sa Akin, o hindi na isasama (luma, walang laman o doble). Mag-search muna sa utak, para ang tao o project na may note na ay ma-update sa halip na magkaroon ng pangalawang note.

Ipakita ang plano sa isang maikling table: ang pinagmulan, kung saan ito pupunta, bagong note o update. Ilagay sa sariling listahan ang mga "hindi isasama".

## 3. Hintayin ang oo

Magtanong (may mga opsyong puwedeng i-click, kung kaya): `Ipasok lahat` · `Baguhin ang plano` · `Huwag na`. Kailangan ng oo na ito para gumawa ng bagong note (pangunahing patakaran 9).

## 4. Ilagay sa lugar

Bago magsulat, gumawa ng backup ng bawat note na babaguhin mo (tingnan ang Backup at Undo sa pangunahing `CLAUDE.md`).

- Gamitin ang info block ng bawat folder (ang `CLAUDE.md` nito) at ang format na "kasalukuyang totoo" para sa mga page sa Tungkol sa Akin at Kontak.
- Isingit ang mga `[[link]]` sa mga tao, kumpanya at project sa loob ng teksto.
- Panatilihin ang mga salita ni {Name}. Paikliin, huwag isulat ulit.
- Mananatili ang mga lumang petsa: ilagay ang mga ito sa mga linya ng ebidensya, hindi sa note ngayong araw.

## 5. Tapusin

Magsulat ng isang linya sa note ngayong araw: ano ang na-import, ilang note ang ginawa at na-update. Saka imungkahi ang isang check-up ("i-check up ang utak ko") para mahuli ang mga doble at kulang na link.
