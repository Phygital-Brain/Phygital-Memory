ہر پروجیکٹ ایک فولڈر ہے جو معلومات آنے کے ساتھ بڑھتا جاتا ہے۔ `README.md` اس میں داخل ہونے کا واحد دروازہ ہے۔

## کون سی چیز کہاں

| مواد | کہاں جائے |
|---|---|
| خلاصہ، اسٹیٹس، آخری تاریخ، اگلے قدم | `پروجیکٹس/{name}/README.md` |
| {Name} کے کام کے نوٹس | `پروجیکٹس/{name}/نوٹس/{topic}.md` |
| ریسرچ | `پروجیکٹس/{name}/ریسرچ/{topic}.md` |
| بریف، تفصیلات، ضرورتیں | `پروجیکٹس/{name}/بریفس/{name}.md` |
| ڈرافٹس، اسکرپٹس، لکھا ہوا مواد | `پروجیکٹس/{name}/ڈرافٹس/{name}.md` |
| آئیڈیاز | `پروجیکٹس/{name}/آئیڈیاز/{name}.md` |
| فیڈبیک | `پروجیکٹس/{name}/فیڈبیک/{name}.md` |
| تصویریں اور میڈیا | `پروجیکٹس/{name}/میڈیا/` |
| اس پروجیکٹ کا پرانا مواد | `پروجیکٹس/{name}/آرکائیو/` |

فولڈروں کے نام چھوٹے حروف میں، ہائفن کے ساتھ، شروع میں کوئی نمبر نہیں (`ریسرچ/`، نہ کہ `01-Research/`)۔ اگر ان میں سے کوئی فٹ نہ بیٹھے تو پروجیکٹ اپنا فولڈر بنا سکتا ہے۔

## README کی ترتیب

1. انفو بلاک (نیچے دیکھیں)، `description` کے ساتھ۔
2. `## یہ کیا ہے`: ایک یا دو لائنیں، [[اہداف]] سے لنک کے ساتھ۔
3. `## اسٹیٹس اور اگلا قدم`: کام کہاں تک پہنچا، اگلا قدم۔
4. `## یہ کیسے چلتا ہے`: صرف اگر کوئی خودکار چیز یہاں لکھتی ہو (شیڈول کیا ہوا ٹاسک، کوئی اسکرپٹ)۔
5. `## کون سی چیز کہاں ہے`: صرف جب ذیلی فولڈر بن جائیں۔ ایک چھوٹی ٹیبل جو ہر ایک کا لنک دے۔

## انفو بلاک (frontmatter)

```yaml
---
type: notes
date: 2026-10-13
status: active
project: Website-Redesign
tags: [website-redesign, notes]
---
```

- `type`: `project` (README، جس میں `created`، `updated` اور `description` بھی ہوتے ہیں)، `notes`، `research`، `brief`، `draft`، `idea`، `feedback`، `plan`۔
- `status`: `active`، `paused` یا `done`۔ README کا اسٹیٹس ہی پروجیکٹ کا اسٹیٹس ہے۔
- `project`: پروجیکٹ کے فولڈر کا نام۔
- `tags`: پہلے پروجیکٹ، پھر قسم۔

## اصول

- نیا پروجیکٹ بس ایک `README.md` ہے۔ ذیلی فولڈر صرف تب بنائیں جب ایسا مواد آئے جسے ان کی ضرورت ہو، اور README سے ان کا لنک دیں۔
- README فہرست ہے۔ اس میں ذیلی فولڈروں کا مواد نہ دہرائیں۔
- پروجیکٹ کے اندر کوئی `CLAUDE.md` نہیں۔ کسی ایک پروجیکٹ کے اصول نیچے "ہر پروجیکٹ کے اپنے اصول" میں جاتے ہیں۔
- ہر متعلقہ نوٹ کے انفو بلاک میں `project:` شامل کریں۔
- مکمل ہوا پروجیکٹ `یادداشت/آرکائیو/{name}/` میں صرف تب جاتا ہے جب {Name} کہیں۔
- ہر پروجیکٹ کو [[اہداف]] کے کسی ہدف کے کام آنا چاہیے۔ چیک اپ میں، بغیر پروجیکٹ والے اہداف اور بغیر ہدف والے پروجیکٹس کی نشاندہی کریں۔
