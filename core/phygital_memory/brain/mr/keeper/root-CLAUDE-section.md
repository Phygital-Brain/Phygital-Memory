## ब्रेन कीपर

ब्रेन कीपर हा ब्रेन दोन प्रकारे सांभाळतो. त्याच्या फाइली `स्किल्स/ब्रेन-कीपर/` मध्ये आहेत.

- **रोज, आपोआप:** `स्किल्स/ब्रेन-कीपर/रोजची-आवराआवर.md` ची ठरलेल्या वेळी होणारी फेरी. छोट्या सुरक्षित दुरुस्त्या, एक अहवाल, आणि फक्त {Name} ज्यावर निर्णय घेऊ शकतात अशा गोष्टींची यादी `स्किल्स/ब्रेन-कीपर/बाकी-मुद्दे.md` मध्ये.
- **तपासणी, {Name} सांगतील तेव्हा:** "माझ्या ब्रेनची तपासणी कर", "माझा ब्रेन नीटनेटका कर" ("check up my brain", "tidy my brain"), किंवा हेच {Language} मध्ये: `स्किल्स/ब्रेन-कीपर/तपासणी.md` वाचा आणि त्याप्रमाणे करा.
- "ब्रेन कीपर चालव" ("run the brain keeper"), किंवा हेच {Language} मध्ये: `स्किल्स/ब्रेन-कीपर/रोजची-आवराआवर.md` वाचा आणि आत्ता एक फेरी करा.
- "ब्रेन कीपर क्लाउडमध्ये चालव" ("run the brain keeper in the cloud"), किंवा हेच {Language} मध्ये: Phygital Brain च्या `brain-keeper` स्किलमधील Step 3, "In the cloud", प्रमाणे करा.
- "ब्रेन कीपर थांबव" ("pause the brain keeper"), किंवा हेच {Language} मध्ये: `स्किल्स/ब्रेन-कीपर/थांबवले.md` बनवा, त्यात एक ओळ: आजची तारीख आणि "{Name} यांनी थांबवले". एका ओळीत खात्री द्या.
- "ब्रेन कीपर पुन्हा सुरू कर" ("resume the brain keeper"), किंवा हेच {Language} मध्ये: `स्किल्स/ब्रेन-कीपर/थांबवले.md` डिलीट करा (या फाइलसाठी लिंक तपासायची गरज नाही). एका ओळीत खात्री द्या.
- "ब्रेन कीपरने काय केलं?" ("what did the brain keeper do"), किंवा हेच {Language} मध्ये: `स्किल्स/ब्रेन-कीपर/अहवाल/` मधील सगळ्यात नवीन अहवाल वाचा आणि सोप्या शब्दांत समजावून सांगा. काही अनपेक्षित असेल तर ते सांगा.
- रोजची फेरी काय करते ते बदलायचे असेल तर {Name} चॅटमध्ये सांगतात. फक्त तेव्हाच `रोजची-आवराआवर.md` बदला.
- अनाथ नोट्स (ज्यांना कोणतीही नोट लिंक करत नाही) शोधताना तपासणी `स्किल्स/ब्रेन-कीपर/अहवाल/` आणि `बाकी-मुद्दे.md` वगळते.
