पुन्हा पुन्हा वापरता येणाऱ्या साहित्याची लायब्ररी: प्रॉम्प्ट, नमुने, पद्धती, संदर्भ साहित्य. ती छोटी ठेवा.

## नियम

- {Name} एखादी पुन्हा वापरता येणारी गोष्ट देतात तेव्हा ती स्पष्ट फाइल नावासह इथे जतन करा.
- एकाच प्रकारच्या अनेक फाइली झाल्या तरच उपफोल्डर बनवा (उदाहरणार्थ `प्रॉम्प्ट/`, `नमुने/`, `पद्धती/`).
- प्रकल्प आणि रोजच्या नोट्समधून साहित्याला `[[wikilinks]]` ने लिंक करा.
- संशोधन `स्मृती/` मध्ये जाते, चालू प्रकल्पांच्या फाइली `प्रकल्प/` मध्ये. त्यांच्या प्रती इथे करू नका. त्यांची लिंक द्या.
- डाउनलोड करता येणाऱ्या फाइलींच्या किंवा इतरांच्या कामाच्या प्रती नाहीत. त्याऐवजी ते कुठे मिळते ते लिहून ठेवा.
