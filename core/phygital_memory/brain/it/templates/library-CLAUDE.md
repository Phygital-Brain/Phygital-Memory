La libreria dei contenuti da riusare: prompt, modelli, metodi, materiale di riferimento. Tienila piccola.

## Regole

- Quando {Name} condivide qualcosa che si può riusare, salvalo qui con un nome di file chiaro.
- Crea sottocartelle solo quando ci sono diversi file dello stesso tipo (per esempio `prompt/`, `modelli/`, `metodi/`).
- Collega le risorse da progetti e note del giorno con i `[[wikilink]]`.
- Le ricerche vanno in `Memoria/`, i file dei progetti in corso in `Progetti/`. Non duplicarli qui. Metti un link.
- Niente copie di file scaricabili o di lavori di altre persone. Scrivi invece dove trovarli.
